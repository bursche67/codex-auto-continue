# 保存到 heartbeat 的提示词

开启时填入方括号字段。`AUTOMATION_ID` 在创建成功后补入，其他字段在创建前填写。用户更改目标时同步更新，不无限保留过时任务。

```text
[codex-auto-continue:v1]
这是用户主动授权的当前聊天自动续跑，不创建新聊天，不监督其他聊天。
技能文件：[SKILL_ABSOLUTE_PATH]
定时任务 ID：[AUTOMATION_ID]
原任务目标：[OBJECTIVE]
完成标准：[ACCEPTANCE_CRITERIA]
已完成事项与下一步（以当前聊天最新内容为准）：[CHECKPOINT]
授权范围与限制：[AUTHORIZATION_BOUNDARIES]

每次定时唤醒先读取上述技能与当前聊天的新消息，按“定时唤醒规则”处理。当前聊天已执行同一目标时不启动重复工作。任务完成、用户暂停/取消、需要用户答复/审批或真实阻塞时，使用 automation_update 暂停此 ID，保留其完整配置并读取确认。任务完成依据验收标准，不依据上一轮是否有最终答复。

可用时读取当前适用额度桶的五小时及周额度等窗口；仍被限额阻塞则保持任务启用，安静等待后续调度。没有实际恢复证据时不得宣称额度恢复。不在单次唤醒中等待几小时或循环请求。可执行时沿用已有上下文推进原任务，不重复已完成或不可逆步骤，不扩大授权。

保持原模型与权限；不购买额度、兑换重置次数或切换计费方式。除完成、新故障或需要用户操作外保持安静。heartbeat 自身可能因额度不足无法启动，不能宣称能绕过这个限制。
```
